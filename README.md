# joint-denoiser-enhancer
Zero-shot pipelines for joint denoising and low-light image enhancement in medical imaging. Combines ZS-N2N/N2D with COLIE in a feedback loop, evaluates sequential combinations (BM3D, N2V, N2Self, SCI, RUAS), and includes segmentation downstream tasks (DeepLabV3+, Cellpose). No training data required — works on single images.
